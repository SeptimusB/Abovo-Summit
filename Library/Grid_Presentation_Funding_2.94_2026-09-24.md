# Summit 2.94 — grid presentation and Funding scheduling

Status: **Ready to test** in 2.94. Jon's functional tests below remain required before Alex testing. No client sign-off or commit is implied.

## Behaviour

- Ordinary wheel is vertical; Ctrl+wheel is horizontal; Shift+wheel zooms in 10% steps, 50–200%. Right-click Zoom has in/out/reset actions. Shared support covers native GridControl/GridView/BandedGridView, VGridControl and TreeList, including the Balance Sheet tree's custom fonts. Open popups and modal dialogs retain wheel ownership. A rebuilt Funding VGrid can swallow forwarded native wheel messages, so internal-scrolling VGrids use the supported TopVisibleRowIndex viewport, with Windows' wheel-line setting and high-resolution notch accumulation. Other DIT VGrids retain their outer-page vertical scrolling.
- Zoom is presentation-only, including active cell editors and repeating header/date editors. Source fills, locks, masks, values and colour rules are not changed. Active editor properties are verified distinct from the shared repository item. Preferences live in HKCU/Software/Abovo/Summit/GridPresentation under hashed keys. DIT keys use XML-derived source names: neither control counters nor dataset ordinals survive rebuilding. No workbook save is needed for these local preferences.
- Funding restores the native sticky loan-name header; hover shows Loan name (Funder/Facility). It is the loan strip, not three frozen worksheet rows. Funding uses its internal vertical viewport so that strip remains visible while scrolling. Context Add schedule preselects the clicked loan and date section; other sections remain available for multi-selection.
- Funding context filters hide other loan columns by funder or facility. A new selection replaces the previous filter. Remove filters, or the toolbar's orange **Filter applied** caption, clears filters on built Funding grids. The native WindowsUI glyph retains the application's blue skin; the warning caption is orange. Filters persist per original file path, Funding interface and XML data source. Save As to a different path does not copy those local preferences. An empty result still has the toolbar clear action.
- Filtered records map back through GetDataSourceRecordIndex before rendering, editing, navigating, pasting, copying or scheduling. No filtered rebind or compacted financial datasource is created. 25.2's unbound native filter needs a non-restrictive active criterion to invoke CustomRecordFilter. Every record receives an explicit visible/hidden result so clearing a restored filter restores all loans; its internal criterion panel is hidden in favour of the meaningful toolbar warning.
- Native multi-cell selection uses MouseUp editor activation so dragging selects rather than prematurely opening an editor. Right-click inside a selection retains it while scheduling/filtering uses the actual clicked loan. Funding's additional **Copy with Header and Row titles** action includes loan-name columns and section/date rows. Other grids keep their existing copy actions.
- Scheduler offers End date or Number of occurrences (including the start date). Intervals remain Monthly, Quarterly, Semi-annually and Annually; dates repeat from the original anchor, with short-month clamping rather than cumulative drift. Bank-holiday/date-rule controls remain removed.
- Fixed figures use the existing date-first worksheet calculation and change-manager transaction. Unavailable amount cells (locked, non-solid pattern, formula or occupied) are skipped and listed in System Messages plus a dismissible, non-modal notice. Dates and eligible amounts remain; nothing is unlocked or overwritten. Invalid numeric input still rejects/rolls back. Existing callers of the strict API retain their rejection behaviour. One Undo/Redo still groups schedule dates and accepted figures; structural capacity expansion retains its existing separate semantics.
- Stock Description's minimum is 21 characters instead of 42; the existing dummy separator is retained.
