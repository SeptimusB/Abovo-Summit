# Project library

This directory stores reference files supplied for analysis alongside the Abovo Summit source code.

Files are copied here without altering their contents. The original filename is retained so code and analysis can refer to a stable repository-relative path.

## Contents

- `TestFileMigrated.xlsb` — migrated Excel workbook supplied for application/workbook compatibility analysis.
- `TestFileMigrated.analysis.md` — verified workbook identity, compatibility, and stored-error summary.
- `Abovo_Summit_Project_Scope_Audit.md` — durable workbook/VBA/VB.NET architecture and risk audit.
- `Abovo_Summit_Project_Index.json` — compact source-free worksheet, VBA procedure/hash, compiled-file, and `Structure.xml` index; it contains no workbook payload, VBA source, or passwords.
- `Abovo_Summit_Codex_Context_Pack.zip` — compressed project context for future Codex tasks.
